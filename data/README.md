# 出入口经营口径

每个经营日当地时间从 8 时起按半小时编号。O 表示外部，A 为练习地，B 为坡道，C 为等候区。route_map 列出连接和每窗正常通过上限，只允许资料里处于开放的方向。observe_time 是计数实际覆盖窗口，known_at 是收到资料的窗口。闸机值是每个表底下的累计计数，补传记录以同一 sensor、counter_epoch、observe_time 的最后已知有效读数为准。对点验理解为在窗口开始的区内人数或窗口内经过某截面的对应方向人数，由 kind 区分。seal 开始和结束均为当地时段，开始包含，结束排除。

ticket_tranches 记录发布额度，数值是尚可出票的单位票数，补发需要注明原额度版本。terminal_log 的出票、撤销、接收、归还、回执订正各有 event 标识。缺接收回执时不能假定终端没有出票。已出票等待扫码从区域容量中预留实际预计到场人数，团票中的人数按旅客计。已签到且未走完通道的人在出发区统计。区内运营保留量采用 occupancy_limits，通道容量、区域容量均按人计。

独立收尾点验由不同岗位留档。回看某个经营时段时，可用日内点验作资料并把收尾点验用于核对结果。

# 资料口径

每个 block 是一个出发站×开课时段内的随机化簇，stratum 是随机化分层。档位 0、1、2 的计划邀请数是每簇八组中的 0、2、5，各层的档位按同概率分派，档内同行组等概率抽取。结果表按原组标识，改签只改 actual_class。到课人数最多等于登记组员数，手工回传超过时需核对原记录；缺失人数不等于零。关班是营运事件；满员是接待受阻。
时间是经营日零时后分钟，团课要求提前至少十分钟到达。ordinary_hold 含在全班 capacity 内。普通申请可以使用保留席，优惠申请不能。已接受且付款的既有申请已经占席，已发出的未接受邀请不能冒充实到，offer_state 候选只有经理同意才可发布。更新为资料接收事件。
